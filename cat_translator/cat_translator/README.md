# 냥냥이톡 (Cat Translator) — v1 (Android)

고양이 울음소리를 듣고, 12가지 상황(인사/반가움, 배고픔, 위협, 고통 등) 중 하나로 번역해서, 채팅앱처럼 생긴 화면에 고양이가 직접 말하듯 메시지로 보여주고 음성으로도 읽어주는 앱입니다.

## 지금 버전(v1)이 하는 일

1. 앱을 열고 채팅창 아래 마이크 버튼을 누르면 마이크로 소리를 계속 듣습니다.
2. 사전학습된 YAMNet(Google AudioSet) 모델로 "지금 소리가 고양이 소리인지, 어떤 종류(야옹/그르렁/하악질/길게 뽑는 울음 등)인지"를 1초 단위로 판단합니다.
3. 소리의 특성(음높이, 크기, 반복 횟수, 발성이 이어진 시간, 시간대)과 결합해 12가지 상황 중 하나로 매핑하고, 고양이가 보낸 채팅 말풍선처럼 화면에 보여준 뒤 한국어 음성으로도 읽어줍니다.
4. 각 말풍선 아래 "맞아요/아니에요" 버튼으로 피드백을 남기면 기기에 기록되고, 추후 고양이별 개인화 모델을 만들 때 재료로 씁니다. 피드백을 남기면 그 말풍선의 버튼은 감사 메시지로 바뀌고 다시 뜨지 않습니다.
## 알려진 제약 (v1)

- 지금은 **앱을 열어둔 상태에서만** 감지됩니다 (iOS와 동일한 방식으로 통일). 완전한 백그라운드 상시 감지(안드로이드 포그라운드 서비스)는 다음 업데이트에서 추가합니다.
- 12가지 상황 분류는 아직 "우리 고양이 소리 데이터로 학습한 전용 모델"이 아니라, 범용 소리 인식 모델(YAMNet) + 음향 특징 기반 규칙으로 1차 근사한 것입니다. (업계 1위 앱도 실제 정확도가 65~75% 수준이라는 점을 참고해주세요.)
## 빌드 방법

이 저장소를 GitHub에 올리면 `.github/workflows/build_apk.yml`이 자동으로 Flutter/Android 빌드 환경을 띄워 APK를 만들고, GitHub Release에 올려줍니다. 직접 로컬에서 빌드하려면 Flutter SDK + Android SDK가 설치되어 있어야 합니다.

```
flutter pub get
python3 tools/fetch_model.py   # YAMNet 모델/라벨 다운로드
flutter build apk --release
```
